What is Discriminant?

Diskriminan ($D$) adalah nilai pembeda pada persamaan kuadrat yang menentukan banyaknya akar real serta sifat pemotongan grafik terhadap sumbu-X.

Bentuk Umum Persamaan Kuadrat:
\(ax^2 + bx + c = 0\)
Syarat: \(a, b, c \in \mathbb{R}\) dan \(a \neq 0\)
Rumus Utama Diskriminan
\(D = b^2 - 4ac\)

Berasal dari rumus ABC kuadratik: \(x_{1,2} = \frac{-b \pm \sqrt{D}}{2a}\)

3 Sifat Nilai Diskriminan

D > 0 (Positif)

2 Akar Real Berbeda

Grafik memotong sumbu-X di dua titik berbeda (\(x_1 \neq x_2\)).

D = 0 (Nol)

1 Akar Real (Kembar)

Grafik menyinggung sumbu-X tepat di satu titik (\(x_1 = x_2\)).

D < 0 (Negatif)

Tidak Ada Akar Real

Akar imajiner. Grafik tidak menyentuh sumbu-X sama sekali.

Persamaan Aktif
\(1x^2 + 0x - 4 = 0\)

Input Koefisien (Atur Nilai)

a (\(x^2\))

Syarat persamaan kuadrat: \(a \neq 0\)

b (\(x\))
c (konstanta)

Langkah Perhitungan

Rumus:
\(D = b^2 - 4ac\)
Substitusi:
\(D = (0)^2 - 4(1)(-4)\)
Hasil:
\(D = 16\)
Sifat Akar:

Nilai \(D > 0\). Memiliki 2 akar real yang berbeda.

Grafik Parabola

Puncak: (0, -4)
Akar: \(x_1 = -2.00, x_2 = 2.00\)
